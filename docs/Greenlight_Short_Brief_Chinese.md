# Greenlight — 产品简介

一份 200 道题的安全问卷，人工填写通常需要 2–3 天。Greenlight 在 1 小时内完成——而且你做的每一份问卷，都让下一份变得更快。

**当前范围：** **Inbound（入站）** — 收到问卷后快速、准确作答。Outbound（向供应商发问卷并评分）尚未实现。

---

## 问题所在

当供应商想把产品卖给大型企业时，采购方会发来安全问卷——有时 50 道，有时 300 道以上。回答重复、耗时，往往压在一个人身上。各份问卷的答案大同小异，只是措辞不同。

---

## 专为澳大利亚市场打造

主要竞争对手 Hypercomply、Conveyor 均为美国工具，不覆盖澳洲合规框架。Greenlight 为澳洲市场而建。

每位新用户自带 **45 条预置澳洲 GRC 问答**（注册时扩展为约 270 个语义变体），覆盖：

| 框架 | 在澳洲的意义 |
|------|----------------|
| **ASD Essential Eight** | 政府与大型企业普遍要求 |
| **隐私法 / APPs** | 处理澳洲个人数据必遵 |
| **APRA CPS 234** | 受 APRA 监管的银行、保险、养老金 |
| **ISO 27001** | 金融、医疗等行业广泛采用 |

用美国工具的顾问在 Essential Eight 上从零开始；用 Greenlight 第一天就有可用答案。

---

## 工作流程

| 步骤 | 说明 |
|------|------|
| **1. 知识库** | 上传策略、SOC 2、渗透测试等；分块并向量化。也可直接用预置澳洲库 |
| **2. 上传问卷** | Excel（**多工作表**）、Word、PDF；Excel 映射列；可选**截止日期** |
| **3. 生成草稿** | **后台任务**检索知识库与答案库，生成完整答案、Yes/No、置信度与**来源段落**；界面轮询进度 |
| **4. 人工审核** | 编辑、批准或拒绝；用 flag 备注协作；未批准不出导出 |
| **5. 导出** | 写回**原始 Excel 版式** |

---

## 政策新鲜度 — 贴合真实 GRC 流程

系统区分 **「政策正文变了」** 与 **「只是很久没确认」**：

| 情况 | 系统行为 |
|------|----------|
| **替换或删除** 知识库文档 | 引用该政策的已批准答案在答案库标为 **stale（待复核）** |
| **上传 / 替换** 更新 **最后确认时间** | `content_updated_at` 记录内容上次确认时刻 |
| **90 / 180 天** 未替换 | 知识库 **琥珀 / 红色提醒** —「请确认仍准确」；**不**阻止 AI 检索 |
| **审问卷时** | 来源面板显示确认日期与相同年龄提醒 |
| **KB Health** | 主题覆盖分析 + **政策卫生**（待复核答案 + 待确认文档） |

**实务建议：** 政策改版时用 **Replace（替换）**，不要删了重传；关联答案库条目会自动标记待复核。

---

## 复利式答案库

每条批准答案进入可检索库；相似问题自动推荐已审核内容。

**咨询公司模式：** **通用答案**（全客户）与 **客户专属答案**（**数据库查询层**隔离，非界面过滤）；批准时可自动判断，库内可「升级为通用」。

---

## 其他功能

- **分享链接** — 只读进度，无需账号
- **答案版本历史** — 每题编辑轨迹
- **KB Health** — 主题缺口 + 政策卫生
- **截止日期** — 问卷可选；到期前 48 小时邮件提醒
- **回收站** — 软删除；90 天后维护任务自动永久清除
- **团队** — Owner / Admin / Member；单次邀请链接（48 小时有效）
- **审计日志** — 谁、何时、基于什么来源操作

## 准确性与幻觉防护

| 机制 | 作用 |
|------|------|
| 仅基于检索内容生成 | 不用通用知识瞎编 |
| 来源同屏展示 | 审核员对照原文 |
| 置信度标签 | 低置信度重点看 |
| **MANUAL** 标记 | 无匹配则明示，不静默编造 |
| 人工批准闸门 | 未批准不出库 |

系统是 **副驾驶，不是自动驾驶**。

---

## 数据安全与客户隔离

- 客户答案在 **SQL 检索层**隔离，结构上无法串客户
- 工作空间级数据边界
- 批准与导出写入不可篡改审计日志
- S3 兼容存储；httponly Cookie + CSRF 双提交

---

## 已知局限

- 每个问卷同时仅 **一个** 生成任务（不同问卷可并行）；生成 worker 与 API 同进程
- 上传、知识库、批量生成需 **已验证邮箱**（`TESTING=true` 开发环境可跳过）
- 逐题分配已移除 — 用 **flag_note** 标记
- 尚无合规 **框架控制项映射**（Essential Eight 等级、ISO 附录 A 等）
